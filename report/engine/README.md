# report/engine/ — supporting historical documents

The polished, current report lives at the repo root: **`README.md`** (also split into `report/report.md`,
`report/ARCHITECTURE.md`, `report/MECHANISM.md`, `report/CHALLENGES.md`).

This folder holds the detailed, round-by-round documents those were distilled from — kept for provenance and for
anyone who wants the fuller, less-edited account of one specific piece:

| File | What it has that the main report doesn't |
|---|---|
| `MAP_LANDMARK_APPROACH.md` | The full round-2 map-matching investigation, section by section, including intermediate results not carried into the final report |
| `SPEED_MODEL_REPORT.md`, `SPEED_MODEL_THEORY.md` | The learned speed model's mechanism explained at greater length, with more worked examples |
| `TRICHY_REPORT.md` | The full India validation write-up |
| `EXECUTION_LOG.md` | Every script run, in order, with what it resolved and what it didn't |
| `DECISIONS.md` | The settled process rules (metric, blackout sets, train/test split) |
| `HANDOFF.md`, `PROJECT_SUMMARY.md`, `HOW_WE_GOT_HERE.md`, `MAP_ENGINE_REPORT.md` | Earlier-stage narrative and handoff notes, superseded by the current report but kept for history |

None of these are required reading — the root `README.md` is complete on its own.
